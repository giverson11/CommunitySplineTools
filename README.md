# S&box Community Spline Tools
Facepunch's spline tools fixed and updated

## Features: 
- Model Offset now works properly and does not converge to the spline center
- Start and end caps are added as optional features to the spline model renderer and Spline Collider
- Surface Velocity of Spline Collider now assigns the velocity locally to each spline segment. (should follow the direction of the spline)

Let me know of any issues you come across and feel free to fork or use for whatever.
